# Session report — 2026-11-11 — Step 4: Art direction, asset pipeline & look development

## Goal
Lock in the visual identity and a repeatable asset pipeline (checkpoints 4A pipeline + kits + rig, 4B look-dev scene + style guide): a style guide, scripted Blender generators for a modular kit, Godot import conventions with automatic material remap, the shared shader/material library, environment presets with fog/glow/SSAO/grading and camera snow, runtime quality presets, a retargeted humanoid character pipeline with the first zombie, the first hero weapon model (M1911), and a finished-quality look-dev slice of the Frozen Courtyard plus a lobby corner.

## Decisions & deviations
- D-027 … D-032 (ARCHITECTURE §14): scripted assets via `bpy`; BoneMap retargeting with shared AnimationLibrary resources; `Graphics` autoload + QualityPreset; Forward+ screenshots on lavapipe; viewmodel reflection sky; `WeaponDefinition.world_scene`.
- New folders: `core/render/`, `core/art/`, `content/{kits,props,environments,quality}/`, `tools/lookdev/` (ARCHITECTURE §3 updated).
- "CC0 humanoid base / CC0 animation library": the container can only reach package registries and GitHub, so the base, rig and clips are **generated in-house** (license-clean). The retargeting path is exercised for real: the library comes from a different skeleton and imports through the profile BoneMap. CC0 or Mixamo clips drop in the same way (ART_PIPELINE §5).
- Kit and props use world-space triplanar detail instead of UV trim sheets (constant texel density, seamless tiling). Hand-authored 256 px/m textures are deferred to Step 13.
- Wall colliders overlap neighbours by 5 mm: the seam test found a ray exactly on a window/door seam slipping between colliders (float precision).
- Generators are content-deterministic. Multi-material joined meshes may differ only in triangle order between runs (glTF exporter).
