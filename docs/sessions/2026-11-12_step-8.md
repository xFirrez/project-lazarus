# Session report — 2026-11-12 — Step 8 (8A + 8B): Vesper Peak full greybox → M3

## Goal
Build the whole Vesper Peak layout (VESPER_PEAK §2–5) in greybox with gameplay-accurate dimensions: every zone, door, barricade and spawner, navigation, the power switch and power-on sequence, the traversal machines (gondola, freight lift, laundry chute, Reactor Bridge placeholder), typed markers for every later feature, a navigation validation tool, a flow bot with travel-time measurements, occlusion / visibility ranges, and a minimap debug overlay. Both checkpoints were done in one session.

## Completed
- **Map structure:** `vesper_peak.tscn` instances 12 zone scenes (`zones/Z01…Z13_*.tscn`); each `VesperZone` script builds `Geometry/ Gameplay/ Lighting/ Audio/` from box / wall-with-openings / ramp / corridor / stair helpers with the Step 4 kit materials (D-053). Datum y 0 = Arrival Station floor. The Z01 hall and the positions the co-op tests use are unchanged.
- **Zones / doors / spawners:** 12 zones with symmetric adjacency in `map_definition.tres`; all 14 doors with §2.2 costs (17,000 total), unlocking both sides' zones; 70 spawners — barricaded windows with zombie bays, risers, vents (crawlspaces), skylight / chute / shaft drops, wall / cliff / floor-grate / pit-rift climbs (new `ZombieSpawner.Kind.CLIMB` + JUMP links), door-burst closets.
- **Navigation:** `NavTiles` (core) bakes 28 tiles from one collider parse; tiles join through edge connections; doors re-bake only touched tiles (D-051). `CrowdDirector.snap` is tile-local and path serving has a time cap (D-056).
- **Power:** `PWR_MainSwitch` (`PowerSwitch`) → `power.main` flag; `PoweredLight` cascade by zone (Z09 first, 0.7 s per step) with flicker, sting + klaxon; markers with `requires_power` light up; machines and powered interactables refuse without power (D-054).
- **Traversal:** `TraversalMachine` (core/machines): gondola Z01 ↔ Z07 (8 s, 500, 30 s cooldown; cabin gates, station gates, in-cabin + station consoles), freight lift Z06 ↔ Z12 (6 s, free, 20 s; zombies ride via `TraversalLink.Action.LIFT`); host validator subtracts machine displacement (D-052). `Chute` + `ShootableGrate` (Z05 → Z12, 5 s slide through a sealed tube). Reactor Bridge = inverted NavDoor (`solid_when_open`), `bridge` console command. Map rules unlock arrival zones when a machine arrives / the chute opens.
- **Markers:** `MapMarker` (typed, canonical id, zone, optional power lamp) for perks, box locations, wall-buys, traps, hazards, relays, Forge, workbench, Conduit parts, EE objects, lore, reels, music boxes, ravens, secrets — 108 in `markers_manifest.json` (+ generator `tools/gen_vesper_manifest.py`). Live wall-buys: M14, Coachgun.
- **Tools / tests:** `tools/run_sim.sh nav_validate` and `flow` (shared `tests/sim/map_analysis.gd`), `perf_arena --map=vesper_peak`, `tools/net_tests.sh traversal`, `tests/integration/test_vesper_markers.gd`; `round_flow` updated for the larger Z03.
- **Debug:** `minimap` overlay (zones unlocked / active, player + zombie + machine dots), `power`, `bridge`, `machine`, `zone_tp`, `markers`, `nav_tiles`.
- **Occlusion / perf:** one OccluderInstance3D per zone floor / rock / cavern roof; visibility ranges on small props, markers, labels; light distance fade.
