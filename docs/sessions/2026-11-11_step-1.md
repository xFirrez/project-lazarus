# Session report — 2026-11-11 — Step 1: Foundation, toolchain & networked skeleton

## Goal
Create the Godot 4 project, folder layout, autoloads, tooling (tests, lint, CI, coop launcher, screenshots), the networking layer v1 with NetSim, the debug console/overlay, and a sandbox where every peer's placeholder capsule is replicated with interpolation, in solo and co-op.

## Completed
- **Engine pinned:** Godot 4.7.2-stable (`tools/godot_version.txt`, `tools/install_godot.sh`). `game/project.godot`: Forward+, Jolt, 60 Hz physics, physics interpolation, physics and render layer names, untyped declarations = error, input map generated from `core/autoload/input_defaults.gd` (`tools/gen_input_map.sh`).
- **Layout** per ARCHITECTURE §3 (`core/`, `content/`, `maps/`, `tests/`), `.gitignore`, `.gitattributes` (LFS patterns), `gdlintrc`.
- **Autoloads:** `Log` (ring buffer), `Config` (ConfigFile settings + rebindable bindings, per-profile), `EventBus`, `Content` (scans `content/` + `maps/` for id'd resources; `MapDefinition`), `Audio` (buses Master/Music/SFX/Weapons/Zombies/UI/VO/Ambience, named events, synthesized placeholder tones), `Pools`, `Net`, `Debug`, `Game` (Boot → MainMenu → Lobby → Loading → InMatch → GameOver with placeholder screens).
- **Net layer v1** (`core/net/`): `NetTransport` + `OfflineTransport` + `EnetTransport`; host/join by IP:port; hello/welcome handshake with peer list and join/leave events; `player_uid` (UUID v4) persisted per profile; reliable message channel (`Net.send_reliable` + registered handlers) and unreliable byte streams (`Net.send_unreliable`); clock sync (`ClockSync`, ping/pong every 0.5 s); `NetSim` (latency, jitter, loss; reliable traffic delayed but ordered, never dropped); host-loss detection; per-second bandwidth/loss stats. CLI: `--solo`, `--host[=port]`, `--join=ip[:port]`, `--netsim=ms,jitter,loss`, `--map=`, `--profile=`, `--exec=`, `--overlay`.
- **Debug console** (`~`): `CommandRegistry` with typed args, defaults, quoted tokens, autocomplete, help/usage; console UI with log view, Tab completion and history. Commands: `help`, `net_status`, `netsim`, `overlay`, `log_level`, `quit`, `host`, `join`, `solo`, `leave`, `game_state`. **Overlay** (F3): FPS, avg/max frame time, role, peers, RTT, KB/s in/out, loss, NetSim.
- **Sandbox** `maps/_test/sandbox.tscn` (+ `sandbox_map.tres`): floor, two ramps, platform, boxes, four spawn markers, two screenshot cameras. `PlayerSync` spawns a `TempCapsule` per peer; owner sends state at 30 Hz, host relays per-entry-stamped snapshots at 20 Hz; remote capsules play back through `InterpolationBuffer` (100 ms base, jitter-adaptive).
- **Tools:** `check.sh`, `run_tests.sh unit|integration|net|all`, `net_tests.sh`, `run_coop_local.sh`, `run_sim.sh smoke`, `screenshot.sh`, `gen_input_map.sh`. **CI:** `.github/workflows/ci.yml` (check, integration, net loopback, smoke).
- Docs: `docs/ASSET_LICENSES.md`, `docs/sessions/`, ARCHITECTURE decisions D-009…D-015, PROGRESS.md, root `PROGRESS.md` (session-chain hand-off), README CI badge.

## Decisions & deviations
- D-009 … D-015 in ARCHITECTURE §14 (version pins, message/stream channels with NetSim at the sender, per-entry snapshot stamps, input map source of truth, opengl3 screenshot fallback, host-loss timeouts, per-profile identity).
- Input actions: GAME_DESIGN has no explicit action list, so a full Zombies-style set was defined in `input_defaults.gd` (move/look, jump, sprint, crouch, fire, aim, reload, interact, melee, lethal, tactical, placeable, weapon next/prev/slots, scoreboard, pause, console, overlay) with gamepad defaults.
- The Lobby state is entered but immediately proceeds to Loading on the host (real lobby is Step 7). Clients wait in Lobby for the host's `_match_start`.
- Audio shuts down and waits 0.15 s before quitting to avoid "ObjectDB instances leaked" warnings from a playback started in the same frame.
